# GOES-18

Products from GOES-18, the GOES-West satellite. NOAA and NESDIS produce the data
and remain the authoritative source. The collections here are mirrors that hold
references and metadata, not pixel data.

## What is here

One collection so far: `abi-l2-fdcc`, the ABI Level 2 Fire/Hot Spot
Characterization product for the CONUS scene.

## License

NOAA publishes the source data. The collection carries a link to NOAA's data
policy. A catalog license value is an open question.

## Provenance

Mirror of the `noaa-goes18` bucket. Upstream: <https://registry.opendata.aws/noaa-goes/>.
