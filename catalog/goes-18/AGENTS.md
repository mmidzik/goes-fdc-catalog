# AGENTS.md — GOES-18

Guidance for AI agents and automated clients working with this sub-catalog.

**One rule survives every edit to this file.** Every claim here is either quoted
from a source or measured from the data.

## What this sub-catalog holds

One collection, `abi-l2-fdcc`. The orbital slot recorded in the NOAA files
read for this catalog (2025-01-07 and 2025-01-08) is `GOES-West`. A satellite's
slot can change over its life, so check the `orbital_slot` attribute in the
file for the date you need.
