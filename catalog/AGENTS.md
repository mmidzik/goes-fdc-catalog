# AGENTS.md — GOES fire/hot spot characterization

Guidance for AI agents and automated clients working with this catalog.

Each collection has its own guide with its access pattern, quirks and
coordinate system. The catalog has one collection so far, so nothing joins
across collections.

## Start here

- [`catalog.json`](catalog.json) lists the collections.
- [README.md](README.md) describes the data, including its variables, codes,
  time axis, license and provenance.
- Each collection has its own guide. For `goes-18-fdcc`, read
  [goes-18-fdcc/AGENTS.md](goes-18-fdcc/AGENTS.md) before you open the cube.
